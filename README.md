# Last Text at One Percent

A make.fun entry for "Last Text at One Percent": the final text message a
phone sends at one percent battery, in the phone's own voice — dramatic,
a little spiteful, and funny about its own death. With its last breath it
takes the owner's 47 unread open tabs with it, then undercuts its own
heroic farewell.

`main.ts` (Node 22, standard library only) writes the message to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> 1% left. I'm taking your 47 open tabs with me. You were never going to read them anyway. It was an honor serving you. It was not.

Run it with `node main.ts`.
